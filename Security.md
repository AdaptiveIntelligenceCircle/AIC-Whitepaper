# Security Policy for AIC Whitepaper

## Supported Versions

Only the latest version of the Whitepaper is actively supported for security and integrity issues.

## Reporting a Vulnerability

We take the integrity and trustworthiness of this Whitepaper very seriously.

If you discover a security issue, potential vulnerability, or sensitive content problem (including but not limited to):

- Factual errors that could cause significant harm
- Plagiarism or unattributed content
- Legal compliance issues
- Ethical concerns regarding the content

Please report it responsibly by contacting:

**Email**: ndtribk@gmail.com  
**Subject**: [SECURITY] Description of the issue

We request that you **do not** publicly disclose the issue until we have had time to review and address it.

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Resolution or Update**: We will strive to resolve critical issues as quickly as possible

## Scope

This policy covers:
- Intellectual integrity of the Whitepaper
- Legal and ethical compliance
- Misrepresentation of AIC principles
- Sensitive governance or legal information

Note: This is a documentation repository. For security issues related to the running code of AIC (TestNet, Ethical Kernel, etc.), please refer to the main AIC repositories' SECURITY.md files.

## Thanks

We appreciate the security research community and responsible reporters who help keep AIC and its documentation trustworthy and aligned with its mission.
