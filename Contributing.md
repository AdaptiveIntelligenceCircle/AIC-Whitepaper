# Contributing to AIC Whitepaper

This Whitepaper is released under CC BY-NC-ND 4.0  — you are free to fork. 

However, to maintain coherence with the project philosophy, we encourage contributors to respect:
- Third Path Absolute
- Zero-Donation principle
- Ethical-from-Kernel architecture

**How to contribute**:
1. Fork the repository
2. Create a new branch
3. Submit Pull Request with clear description
4. All contributions remain reusers to copy and distribute the material in any medium or format in unadapted form and for noncommercial purposes only.

**Moreover**: 
- Typo fixes, broken links, clarity edits (preserve meaning).  
- Translations: mark translator; do not alter normative claims.  
- Issue reports: factual errors, ambiguity, outdated status.

## Not in scope via drive-by PR

- Silent insertion of tokenomics, dual-license capture, or “AIC is endorsed by X.”  
- Changing Ethical Kernel bits only in the paper without governance/code process.  
- Inflating Mainnet / community status.

Normative changes to protocol behavior belong in governance and code repositories, then reflected here.
